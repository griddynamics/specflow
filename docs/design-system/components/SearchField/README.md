A capsule search input with a magnifier and a clear button.

**Provide:** `placeholder` (say what is searched: "Search connectors"), `value`/`onChange` or `defaultValue`, `label` if the placeholder is not enough.

Filter as the user types; show the result count nearby. Sits on glass so it works over imagery and in filter rows.
