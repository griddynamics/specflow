Placeholder shapes that shimmer while content loads.

**Provide:** `variant` (`text` with `lines` · `block` · `circle`), `width`, `height`.

Match the shape of what's coming (a FileRow, a card, a paragraph) so the layout doesn't jump. Use for waits over ~300 ms; shorter waits need nothing.
