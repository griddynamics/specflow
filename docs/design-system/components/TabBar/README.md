A floating glass capsule of 2–5 section tabs for mobile and compact app layouts; the selected tab sits in a yellow-tinted glass lens.

**Provide:** `tabs` (`{value, label}`), `value`/`onChange` or `defaultValue`.

Pin it `space-sm` above the bottom safe area, centred. Labels are short nouns (Home, Projects, Insights, Team). It shrinks back on scroll in an app; keep it static here. Icons: use the brand icon set or a flagged Phosphor substitute, never emoji.
