A centred glass card that explains why a screen is empty and offers the next step.

**Provide:** `title` (what's missing, sentence case), body as children (one or two sentences: why it matters), `icon` (shown in a yellow-glass tile) or `media`, `actions` (one primary Button, optionally a plain one).

Use for empty projects, empty search results and first-run screens. Keep it to one primary action.
