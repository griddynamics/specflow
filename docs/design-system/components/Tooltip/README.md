A short glass label that appears on hover and keyboard focus.

**Provide:** `label` (2–5 words), `side` (`top` default · `right` · `bottom` · `left`), and the element it describes as the child.

For icon-only buttons the label must also be the button's `aria-label`; the tooltip is a visual aid, not the accessible name. Never put essential instructions in a tooltip.
