Pill labels for categories and statuses: the only shape the GD deck system has always rounded.

**Provide:** a 1–2 word label; `tone`: `neutral` (glass), `accent` (yellow, one per card), `info`, `success`, `danger`, `warning` (yellow tint, "Needs attention"), `pending` (small spinner, "Checking").

Status tones show a dot (pending shows a spinner) plus coloured text (`info`, `success`, `danger` tokens on `glass-fill-strong`); the word carries the meaning, never the colour alone.
