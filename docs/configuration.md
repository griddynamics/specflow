# Configuration

Every setting is an environment variable. A few storage settings can also come from a
cloud profile file. This page lists all of them.

Classes used below:

- **K** - keep: the deployment must set it. It is in `.env.example` with an empty value.
- **D** - default: the code has a default. Set it only to change the default.
- **C** - cloud profile: comes from the cloud profile file; an environment variable overrides it.
- **L** - local: set by `docker-compose.yml` and the `Makefile` for the local stack, or generated by `make env-local`.

Services: **api** (HTTP API), **worker-parse** and **worker-agents** (Temporal workers),
**mcp** (MCP server), **frontend** (Next.js app), **tools** (examples and live tests).

## Required settings (K)

| Name | Read by | Meaning |
|---|---|---|
| `APP_ENV` | api, mcp, workers, frontend | `local`, `dev` or `prod`. A value other than `local` turns on the start-up guards. |

| `DATABASE_AGENT_PASSWORD` | api, workers | Password of the role that agent tools use (row-level security). |
| `NEO4J_URI`, `NEO4J_USER`, `NEO4J_PASSWORD` | api, mcp, workers | Graph database connection. |
| `TEMPORAL_ADDRESS`, `TEMPORAL_NAMESPACE` | api, workers | Workflow engine address and namespace. |
| `LLM_GATEWAY_URL`, `LLM_GATEWAY_API_KEY` | api, workers | OpenAI-compatible gateway route (no `/v1` suffix) and its key. |
| `AGENT_MODEL` | api, workers | Model id of the agents on the gateway route. |
| `AUTH_ALLOWED_EMAIL_DOMAINS` | api, mcp | Comma-separated list of allowed e-mail domains. |
| `PUBLIC_URL` | frontend | Public URL of the app. |
| `API_INTERNAL_URL` | frontend | URL at which the frontend reaches the API. |
| `OIDC_ISSUER` | api, mcp, frontend | OpenID Connect issuer. Must be `https` when `APP_ENV` is not `local`. |
| `OIDC_CLIENT_ID`, `OIDC_CLIENT_SECRET` | frontend | OpenID Connect client. |
| `SESSION_SECRET` | frontend | Signs the session cookie. At least 32 bytes. |

Published as the `resource` of the protected resource metadata. See [architecture](mcp-server/architecture.md#settings). |
| `DRIVE_IDENTITY_EMAIL` | api, worker-parse | E-mail address of the service identity that must have access to the shared folders. See below. |

|---|---|---|---|

| `TEMPORAL_QUEUE_PARSE`, `TEMPORAL_QUEUE_AGENTS` | `specflow-parse`, `specflow-agents` | api, workers | Task queue names. |

| `AUTH_MODE` | `oidc` | api, mcp, frontend | `oidc` or `dev`. `dev` is for `APP_ENV=local` only. |
| `AUTH_JWKS_URL` | unset | api, mcp | JWKS override on the issuer host. |
| `OIDC_INTERNAL_URL` | unset | frontend | URL at which the frontend reaches the issuer, when it differs from `OIDC_ISSUER`. |
| `AUTH_API_AUDIENCE` | `specflow-api` | api, mcp | Expected token audience. Must differ from every `AUTH_API_CLIENT_IDS` value while `AUTH_TOKEN_TYPE=none`. When audiences are client ids, each surface needs its own client; the `mcp` role checks this against the `AUTH_API_*` values it is given ([refusals](mcp-server/auth.md#token-validation)). |
| `AUTH_API_CLIENT_IDS` | `specflow-web` | api | Comma-separated list of allowed token client ids. |
| `AUTH_SUBJECT_CLAIM` | `sub` | api, mcp | Claim that holds the user id. Choose it before the first sign-in: changing it re-keys users. See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `AUTH_CLIENT_ID_CLAIM` | `azp,client_id` | api, mcp | Comma-separated client id claims; the first one present in the token is used. See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `AUTH_EMAIL_CLAIM` | `email` | api, mcp | Claim that holds the user email. See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `AUTH_EMAIL_VERIFIED_CLAIM` | `email_verified` | api, mcp | Claim that must be `true`. Empty means no check (not "unset"); use it only for providers that issue verified addresses only. See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `AUTH_TOKEN_TYPE` | `none` | api, mcp | Token type check: `none`, `keycloak` (claim `typ` is `Bearer`), `rfc9068` (JOSE header `typ` as the claim profile defines) or `claim` (the claim `AUTH_TOKEN_TYPE_CLAIM` equals `AUTH_TOKEN_TYPE_VALUE`). Any mode but `none` lets the audience equal a client id (refusals: [auth](mcp-server/auth.md#token-validation)). See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `AUTH_TOKEN_TYPE_CLAIM` | unset | api, mcp | Name of the access-token marker claim. Required with `AUTH_TOKEN_TYPE=claim`, refused with any other mode. Must not be a registered or identity claim (`iss`, `sub`, `aud`, `exp`, `nbf`, `iat`, `jti`, `azp`, `client_id`, `email`, `email_verified`, `acr`, `amr`, `sid`, `auth_time`, `nonce`, `at_hash`, `c_hash`, `s_hash`) or a configured `AUTH_SUBJECT_CLAIM`, `AUTH_CLIENT_ID_CLAIM`, `AUTH_EMAIL_CLAIM` or `AUTH_EMAIL_VERIFIED_CLAIM` name; `typ` is allowed. |
| `AUTH_TOKEN_TYPE_VALUE` | unset | api, mcp | Exact, case-sensitive string the marker claim must hold. Required with `AUTH_TOKEN_TYPE=claim`, refused with any other mode. |
| `AUTH_IGNORED_AUDIENCES` | `account` | api, mcp | Comma-separated audiences dropped before the audience check. Empty means the default. Must not hold `AUTH_API_AUDIENCE`. See [auth](mcp-server/auth.md#claim-profile-for-any-oidc-provider). |
| `MCP_AUDIENCE` | the value of `MCP_RESOURCE_URL` | mcp | Expected token audience of the MCP endpoint. Must differ from every `MCP_CLIENT_IDS` value while `AUTH_TOKEN_TYPE=none`; must never equal `AUTH_API_AUDIENCE`, an `AUTH_API_CLIENT_IDS` value or an `AUTH_IGNORED_AUDIENCES` value. When audiences are client ids, each surface needs its own client; the `mcp` role checks this against the `AUTH_API_*` values it is given ([refusals](mcp-server/auth.md#token-validation)); see [architecture](mcp-server/architecture.md#settings). |
| `MCP_CLIENT_IDS` | `specflow-mcp` | mcp | Comma-separated list of allowed MCP token client ids; at least one. See [architecture](mcp-server/architecture.md#settings). |
| `MCP_ALLOWED_HOSTS` | empty | mcp | Comma-separated `Host` values accepted besides the host of `MCP_RESOURCE_URL`. Exact match, no wildcard. |
| `MCP_ALLOWED_ORIGINS` | empty | mcp | Comma-separated browser `Origin` values accepted. Exact match, no wildcard. Empty refuses every request that carries an `Origin`. |
| `MCP_PORT` | `8002` | mcp | Listen port of the MCP role. See [architecture](mcp-server/architecture.md#settings). |
| `ALEMBIC_CONFIG` | `/app/alembic.ini` | migration job | Path of the migration config. |
| `WORKER_DIAG_STATE` | `<tmpdir>/specflow-worker-state.json` | workers | File for worker diagnostics. |
| `OPENAI_AGENTS_DISABLE_TRACING` | agent SDK default | workers | Standard variable of the agent SDK. |
| `OMP_NUM_THREADS` | unset | workers | Read for diagnostics only. |
| `ORT_DISABLE_TELEMETRY` | CLI sets `1` if unset | tools | Standard variable of the ONNX runtime. |
| `KUBERNETES_SERVICE_HOST` | set by Kubernetes | api, mcp, workers, frontend | Turns on the in-cluster guards. Do not set it by hand. |
| `GOOGLE_APPLICATION_CREDENTIALS` | library chain | api, workers | Standard Google credential chain (key file, Workload Identity). |
| `AWS_ACCESS_KEY_ID`, `AWS_SECRET_ACCESS_KEY` | AWS credential chain | api, workers | Standard AWS credential chain. Prefer an IAM role. |

## Storage settings (C)

These come from the cloud profile file. An environment variable with the same name wins.

| Name | File key | Meaning |
|---|---|---|
| `STORAGE_BACKEND` | `services.object_storage.provider` | `gcs` or `s3`. Default: the first provider of the cloud (`gcp` = `gcs`, `aws` and `local` = `s3`). |
| `STORAGE_BUCKET` | `services.object_storage.bucket` | Bucket name. Required. |
| `STORAGE_PREFIX` | `services.object_storage.prefix` | Folder in the bucket, ends with `/`. Required. A non-local `APP_ENV` refuses `dev/local/`. |
| `GOOGLE_CLOUD_PROJECT` | `services.object_storage.gcs.project` | `gcs` only. Unset = the project of the credentials. |
| `AWS_ENDPOINT_URL_S3` | `services.object_storage.s3.endpoint_url` | `s3` only. Unset = the AWS endpoint. |
| `AWS_REGION` | `services.object_storage.s3.region` | `s3` only. Unset = the AWS client chain. |
| `STORAGE_S3_ADDRESSING` | `services.object_storage.s3.addressing` | `auto` (default) or `path`. |

## Cloud profile file

Set `SPECFLOW_CONFIG_FILE` to the path of a YAML file. If it is unset or blank, only the
environment is used. Precedence, highest first: environment variable, profile file, default.

```yaml
cloud: gcp | aws | local        # required
services:
  object_storage:
    provider: gcs | s3           # optional; default by cloud
    bucket: your-bucket-name
    prefix: prod/
    s3:  { endpoint_url: null, region: eu-west-1, addressing: auto }
    gcs: { project: null }
```

The file has no secrets. An unknown key, an unreadable file or an invalid value stops the
start-up; the message names the key or variable, never a value. Examples:

- `config/examples/cloud.gcp.yaml` - a Google Cloud Storage bucket.
- `config/examples/cloud.aws.yaml` - an S3 bucket. Add a bucket lifecycle rule `AbortIncompleteMultipartUpload` to remove failed uploads.
- `config/cloud.local.yaml` - the local stack (RustFS). `docker-compose.yml` and the `Makefile` point `SPECFLOW_CONFIG_FILE` at it.

S3 keys come from the standard AWS credential chain. A bucket is never created by the app.

## Local stack

Run `make env-local` first: it writes `.env.local` (git-ignored) with random local secrets and
never overwrites an existing file. `make up` then starts postgres, neo4j, RustFS (S3-compatible,
host port `RUSTFS_HOST_PORT`, default `19000`, bucket `specflow-local`), api, mcp (the MCP
endpoint on `127.0.0.1:8002`, dev mode), worker-parse, worker-agents and frontend.
`docker-compose.yml` and the `Makefile` set the local values below.

Temporal and Langfuse are optional. The default stack starts neither: the app uses your own.

| Mode | Command | `TEMPORAL_ADDRESS` in the containers | Langfuse in the containers |
|---|---|---|---|
| Own Temporal and Langfuse (default) | `make up` | `TEMPORAL_ADDRESS` from your shell or `.env.local`, else `host.docker.internal:7233` | `LANGFUSE_BASE_URL`, `LANGFUSE_PUBLIC_KEY`, `LANGFUSE_SECRET_KEY` from your shell or `.env.local`; empty = no tracing |
| Bundled Temporal | `make up WITH=temporal` | `specflow-temporal:7233` | as above |
| Bundled Langfuse | `make up WITH=langfuse` | as above | `http://specflow-langfuse-web:3000`, keys from `.env.local` or the local defaults |
| Both | `make up WITH=temporal,langfuse` | `specflow-temporal:7233` | as the row above |

`make up WITH=keycloak` also starts the local Keycloak (`127.0.0.1:8180`, realm `specflow`) and
switches only `mcp` to `oidc`; the web app and the API keep dev login. See
[MCP local stack](mcp-server/deployment.md#local-stack).

`WITH` sets the compose profiles `temporal` (the dev server), `langfuse` (web, worker,
postgres, clickhouse, redis, minio) and `keycloak`. `make down`, `make ps` and `make logs`
always cover every profile. Set `TEMPORAL_ADDRESS` to an address the containers can reach (not `localhost`). The host
tools (`make api`, `make worker`) use `TEMPORAL_ADDRESS`, default `localhost:7233`.

The app never creates the Temporal namespace (`TEMPORAL_NAMESPACE`, default `specflow-local`).
The bundled Temporal creates it on start. On your own Temporal, create it once:

```shell
temporal operator namespace create --address <host>:7233 --namespace specflow-local
```

## Document source identity

`DRIVE_IDENTITY_EMAIL` is the e-mail address of the identity that opens the shared
folders. Share each folder with this address. If it is unset or blank, document
source calls fail with `setup_error` and the log event `drive.identity.missing`; there is
no fallback to other credentials. The app still starts.
